About this demo

AdamCo is a synthetic SaaS application used as the standards-first target for the Agent Web Graph crawler prototype. It is hand-built to expose:

  • HTML popover (user menu)
  • <dialog> with command="show-modal" (sign out, new ticket, delete workspace)
  • Custom Invoker Commands (command="--toggle-theme")
  • ARIA tabs (Recent / Popular / Archived)
  • ARIA combobox + listbox (docs search)
  • A sidecar design-tokens.json with a tokens.json reference
  • A sidecar webmcp.json declaring three capabilities across tiers

Every page in this demo is a 200 OK anonymous response. The crawler exercises the full five-layer extraction against this surface and writes the result to a single Graph document.
