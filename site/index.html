1-Click Integration

Connect to Your Favorite AI Environment

Full Model Context Protocol compatibility. Works out of the box with Claude Desktop, Cursor, Claude Code, and Zed.

Add this configuration to your claude_desktop_config.json: 
{
  "mcpServers": {
    "nexusos-semantic": {
      "command": "npx",
      "args": ["-y", "nexusos-semantic", "serve", "--desktop", "--mobile"]
    }
  }
}
Add to your project's .cursor/mcp.json: 
{
  "mcpServers": {
    "nexusos-semantic": {
      "command": "npx",
      "args": ["-y", "nexusos-semantic", "serve"]
    }
  }
}
Run this command directly in your terminal to register with Claude Code: 
claude mcp add nexusos-semantic -- npx -y nexusos-semantic serve
Install and run in 1-click via the Smithery MCP registry: 
npx -y @smithery/cli run nexusos-semantic
No Node.js runtime required! Run the Single Executable Application (SEA) directly: 
{
  "mcpServers": {
    "nexusos-semantic": {
      "command": "nexus",
      "args": ["serve"]
    }
  }
}
Built-in Diagnostics & Tooling

Production Grade Reliability

Run self-tests and inspect crawled application health with deterministic scoring.

nexus doctor

Inspects the local runtime, tests BiDi endpoints, verifies Windows UIA/macOS AX daemon access, probes Android ADB, and confirms storage durability.

nexus doctor --json
nexus inspect

Calculates health percentage scores (0-100%) for web graphs, surfacing broken links, missing ARIA accessibility labels, and extractor failures.

nexus inspect --graph ./my-crawl --diagnostics
nexus crawl

Autonomous crawler mapping state transitions, declared ARIA triggers, design tokens, and kinetic element bounding boxes.

nexus crawl "http://localhost:3000" --out ./crawl-data
nexus serve

Starts the high-performance MCP stdio server providing semantic tools (graph_query, graph_path, graph_tool, graph_invoke).

nexus serve --graph ./crawl-data --desktop --mobile
